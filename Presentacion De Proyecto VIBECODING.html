Proyecto: Vibecoding Guiado: Desarrollo de una Aplicación o Mini-Juego con IA como Copiloto

1. Aplicación o Mini-juego Funcional

Descripción del Proyecto:

Se desarrolló un videojuego arcade 2D completo titulado "CyberSpace Arcade" dentro del archivo script space_arcade.py, utilizando Python y la librería gráfica pygame. Presenta una interfaz moderna con resolución base de 800x800 píxeles, ventanas redimensionables y alternancia a pantalla completa (tecla F).

Características Técnicas:

  • Selección de Dificultad: Menú interactivo que escala vidas y velocidad.
  • Sistema de Jefes: Jefes cada 30 puntos con barras de salud, movimiento en senoide y ataques en abanico.
  • Power-ups: Mejoras de armas (niveles 1 a 3), escudos y recuperación de vida.
  • Efectos y Audio: Partículas físicas y audio procedural integrado con pygame.mixer.
  • Persistencia: Récords guardados en formato JSON (highscore.json).

2. Evidencia de Vibecoding

Prompt Base del Proyecto

Qué se pidió a la IA:

"Eres un desarrollador de videojuegos senior con experiencia en Python y Pygame. Necesito un script base, claro y ejecutable, de un pequeño shooter de naves en 2D.

Requisitos del juego:
- Ventana redimensionable de 800x800 píxeles, con título descriptivo.
- Una nave espacial controlada por el teclado, que se mueve con las flechas del teclado o con WASD (ambos deben funcionar a la vez).
- La nave debe mantenerse dentro de los límites de la ventana durante todo el movimiento.
- Disparos frontales: la nave dispara hacia arriba al pulsar la barra espaciadora (o una tecla de disparo clara), con una cadencia limitada para que no se disparen de forma continua e instantánea.
- Meteoros que caen desde la parte superior de la ventana en posiciones aleatorias, con velocidades variables, y que se eliminan al salir por la parte inferior.
- Los disparos deben poder destruir meteoros al impactar; los disparos que salen de la pantalla se eliminan.

Expectativas del código:
- Un único archivo .py autocontenido, ejecutable con python nombre_del_archivo.py.
- Usa un bucle principal estándar de Pygame con control de FPS mediante pygame.time.Clock.
- Organiza el código con clases simples para la nave, los disparos y los meteoros, y comenta brevemente las partes clave en español.
- Gestiona el cierre de la ventana y la tecla Escape para salir limpiamente.
- No añadas puntuación, menús, sonidos ni imágenes externas salvo que sea imprescindible: usa figuras geométricas dibujadas con Pygame."

Por qué se ajustó o refinó:

Este prompt se utilizó como punto de partida técnico para establecer la arquitectura base del bucle de juego (game loop), el manejo simultáneo de entradas de teclado y las restricciones geométricas de límites y colisiones.

2. Evidencia de Vibecoding

Prompt de Expansión (Dificultad y Partículas)

Qué se pidió a la IA:

"Añade un menú de selección de dificultad al inicio (Fácil, Normal, Difícil), un sistema de persistencia de récords máximos utilizando un archivo JSON local, y un sistema de partículas rectangulares con velocidad y vida decreciente para simular explosiones al destruir meteoros."

Por qué se ajustó o refinó:

Se refinó para introducir mecánicas de juego duraderas, escalabilidad de dificultad según el nivel seleccionado y un salto cualitativo en el apartado visual con efectos dinámicos de partículas.

2. Evidencia de Vibecoding

Prompt de Mecánicas Avanzadas (Audio y Jefes)

Qué se pidió a la IA:

"Integra un sistema de audio procedural usando buffers de pygame.mixer para generar efectos de sonido sintéticos de disparos y explosiones, power-ups flotantes de mejora de armas, y un jefe final con movimiento ondulatorio en senoide y disparos en abanico."

Por qué se ajustó o refinó:

Necesario para dotar al juego de un diseño de mecánicas avanzadas y pulidas (game polish), logrando un producto funcional autónomo, inmersivo y sin dependencias de archivos externos.

3. Iteración y Mejora

Modificación principal:

El proyecto evolucionó de un script básico y estático a una aplicación modular basada en clases orientadas a objetos bien definidas dentro de space_arcade.py:

  • Player (Control, armas y escudo)
  • Meteor (Obstáculos y velocidades)
  • Boss (Jefes con patrones complejos)
  • Particle (Efectos visuales)
  • PowerUp (Mejoras flotantes)

Se optimizó el bucle de renderizado para soportar cambios dinámicos de tamaño en tiempo real (pygame.VIDEORESIZE) y controles de pausa avanzados (teclas P y ESC).

4. Validación del Resultado

Cómo se probó el código:

  • Se ejecutó el script localmente validando que la ventana inicial de 800x800 cargara sin errores de sintaxis.
  • Se probó la redimensión y alternancia a pantalla completa con la tecla F.
  • Se verificó la creación automática y lectura del archivo highscore.json al superar el récord.
  • Se probaron colisiones con jefes y recogida de power-ups para validar la progresión de armas.

Error o limitación identificada:

En equipos sin tarjeta de sonido o controladores inactivos, pygame.mixer podía lanzar excepciones críticas.

Ajuste realizado: Se envolvieron las funciones de audio en bloques try-except, asegurando una ejecución estable y fluida aunque no haya hardware de audio disponible.

5. Reflexión Final

Aprendizaje y Ventajas del Vibecoding:

Permite prototipar sistemas complejos (matemáticas de partículas, audio procedural, JSON) en minutos. Su mayor límite es que requiere supervisión humana para equilibrar las reglas del juego (*game balance*) y gestionar excepciones de hardware.

Autoevaluación:

  • Comprendo: El bucle principal por fotogramas (CLOCK.tick(60)), manipulación de listas y manejo de archivos JSON.
  • Necesito reforzar: Técnicas avanzadas de optimización de renderizado para cientos de partículas simultáneas en equipos de bajos recursos.

🛠️ Librerías y Ejecución de space_arcade.py

pip install pygame

Para iniciar y probar tu proyecto ejecutando el script principal:

python space_arcade.py

Librerías nativas de Python integradas (sin instalación extra):
